The ouroboros

A quine is a program whose only output is its own text. This one is a poem: four quatrains on the serpent that eats its tail, said by a word that has nothing to say but itself. Read it as verse. Then run it, and it answers with the whole of itself, every letter and every space, the tail in the teeth.

How it knows itself: a function in JavaScript can be asked for its own text, and since 2019 the language has promised that the answer is the text exactly as written, comments and spaces and all. So the poem lives in a comment inside a function called ouroboros, and the one line of the function that does anything puts back the parentheses that hold it and the call that runs it. What comes back is the program. Some keep a stricter rule for quines, that a program may not read itself; the gnostics would have said that reading oneself is the whole of the work.

To check it without this page, copy the poem into a browser's console and press enter: it says itself back. It is kept as its own file, and this page shows that file and runs it, and compares the two.
