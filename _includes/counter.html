{%- comment -%} The counter. GoatCounter, when _config.yml names a site code; nothing at all when it does not. No cookie and no storage: GoatCounter tells visits apart by a salted hash of the address and browser that it throws away each day, and the site asks it for nothing more than the page. The path sent is the pathname only, and the referrer is cut at its query string; neither the query nor the hash goes, so a chart kept in a temple room's address stays in the address. A browser that asks not to be tracked (Do Not Track or Global Privacy Control) is not counted. On localhost and in a frame count.js already declines on its own. {%- endcomment -%} {%- if site.goatcounter and site.goatcounter != "" %} {%- endif %}
